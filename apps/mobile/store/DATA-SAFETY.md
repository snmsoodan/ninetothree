## What is collected

| Data type | Collected | Shared | Linked to a person | Purpose |
| --- | --- | --- | --- | --- |
| Email Address | Yes | No | Yes | App Functionality |
| Name | Yes | No | Yes | App Functionality |

Nothing else leaves the phone. The shelf, the settings, the cached weeks and the
session live in the app's own storage and are deleted when the app is uninstalled
or you sign out.

## Why each Apple required-reason API is called

Play does not ask for this, and it is here because a reviewer comparing the two
stores should see the same list in both places.

| Category | Reason | Why the app calls it |
| --- | --- | --- |
| File Timestamp | C617.1 | The shelf, the settings and the cached weeks are files in the app's own container. The app reads their modification time to know whether a cached week has gone stale. |
| User Defaults | CA92.1 | React Native and the modules it loads keep their preferences in the app's own defaults, which is the only place they read them back from. |
| System Boot Time | 35F9.1 | Elapsed time is measured against the system's uptime so a timer still works after the device has slept, which is most of a night with a newborn. |
| Disk Space | E174.1 | Available room is checked before a bundle or a cache file is written, and nothing is written when the answer is none. |
| No other API | None | No contacts, photos, camera, microphone, location, health data or advertising identifier is read. |
